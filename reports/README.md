# Reports

Documentation and deliverables from the Rockbuster SQL analysis.

## Contents

- **Rockbuster_Analysis_Results.xlsx** - Detailed analysis workbook with all query results, summary statistics, and supporting tables
- **Rockbuster_Streaming_Campaign_Data_Dictionary.pdf** - Complete database schema documentation including table relationships, field definitions, and data types
- **Rockbuster_Streaming_Campaign_Final.pdf** - Final stakeholder presentation (PDF format)
- **Rockbuster_Streaming_Campaign_Final.pptx** - Final stakeholder presentation (PowerPoint format)

- Market prioritization strategy (Tier-1 and Tier-2 markets)
- Content acquisition recommendations by genre and rating
- Customer segmentation and geographic distribution
- Revenue analysis and business impact projections
